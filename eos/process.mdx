**The Mav Way** — the handful of core processes that make Mav repeatable. Documented "well enough": the **Followed-By-All** bar, not the ISO bar.

This page is the EOS Process component overview. The actual core-process documents live in the [Core Processes](/core-processes/overview) section, one area per function — and Orrery's department **skills** (e.g. `customer-success:at-risk`) hydrate their definitions directly from those docs, so a process a person follows is the same one an agent executes.

## How a core process becomes real

1. **Draft** — the team drafts the process (often collaboratively, from what's already working).
2. **Published** — it's written up in Mintlify under Core Processes; this is the canonical home, the getting-started reference for the team, and the source Orrery reads.
3. **Followed by all** — complete enough that anyone in that function can execute it without asking.
4. **Agentically executed** — where it makes sense, a department skill runs the process (or walks a human through it), pulling its definition from the published doc.

<Note>
  "Followed by all" is the bar: a process is ready when a new team member in that function could run it without asking. That same clarity is what lets Orrery run it as a skill.
</Note>
